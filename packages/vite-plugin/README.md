# @macroforge/vite-plugin

[![JSR](https://jsr.io/badges/@macroforge/vite-plugin)](https://jsr.io/@macroforge/vite-plugin)

## Overview

Vite plugin that expands Macroforge macros in TypeScript and Svelte modules

## Installation

```bash
deno add jsr:@macroforge/vite-plugin
```

```bash
npm install @macroforge/vite-plugin
```

## API

### Functions

- **`macroforge`** - Creates a Vite plugin for Macroforge compile-time macro expansion.

### Constants

- **`default`**
