# fix(deps): move wasm-bindgen to 0.2.130, off a yanked yoke-derive

- **Date:** 2026-10-30 15:17
- **Commit:** 8cf574d88
- **Area:** dependencies, wasm-bindgen-cli setup

## Problem

`pixi run setup:wasm-bindgen` warned that `yoke-derive v0.8.3` in the lockfile is yanked, on every
machine and CI run that installs the CLI.

## Cause

`cargo install --locked` builds wasm-bindgen-cli from its published lockfile, and 0.2.129's pins
yoke-derive 0.8.3, which crates.io later yanked.

## Introduced

4615c7b0a (2026-09-28), `0.4.0: Dropping bloat, architecture improvements`. It pinned wasm-bindgen
and its CLI at 0.2.129; the lockfile went bad when yoke-derive 0.8.3 was yanked afterwards.

## Fix

wasm-bindgen and the CLI `setup:wasm-bindgen` installs move to 0.2.130, whose lockfile has
yoke-derive 0.8.4, with js-sys and web-sys to 0.3.107 in both lockfiles.

## Verified

`pixi run setup:wasm-bindgen` installed 0.2.130 without the yanked warning. `pixi run build:rust`
and `pixi run build:testground:macro` built with it.
