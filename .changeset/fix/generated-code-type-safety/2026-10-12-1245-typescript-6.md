# chore(deps): migrate to TypeScript 6

- **Date:** 2026-10-12 12:45
- **Commit:** b12a3f02, c122c533 (fixup)
- **Area:** Packages, svelte language server, website, testground

## Problem

Every package, the website and the testground were on TypeScript 5.9, two major versions behind.

## Cause

The svelte language server fork was based on upstream 0.17.22, which predates TypeScript 6, and the
rest of the repository stayed on its version.

## Fix

TypeScript 6.0.3 everywhere. That is the last release whose package carries the compiler API: 7
ships only the native compiler, with no `createProgram`, language service or tsserver plugin host,
so the wrappers, the editor plugin and the language server cannot run on it. The peer ranges of the
Vite and TypeScript plugins say `^5.0.0 || ^6.0.0` where they said `>=5.0.0`.

The language server takes upstream's two TypeScript 6 changes (sveltejs/language-tools#2985 and
#2988): the auto-import project factory is chosen by major version, where `minor < 5` picked the 5.0
factory for 6.0, and the fixtures that leaned on the old defaults say `strict: false` and
`module: NodeNext`. The performance fixture drops `use:action` as upstream's did.

The vanilla testground drops `baseUrl`, which 6 deprecates, and `DOM.Iterable`, which is part of
`DOM` in 6.

## Verified

- `macroforge tsc` on the vanilla testground exits 0 and `macroforge svelte-check` on the svelte
  testground reports 0 errors in 881 files, both on 6.0.3.
- The language server suite: 638 passing and 5 failing on 6.0.3 before the fixtures moved (three
  snapshots of TypeScript's messages and lib line numbers, a union's member order, and the
  performance test's timeout), 643 passing and 0 failing after.
- The TypeScript plugin's tests: 50 pass.
- The testground's Deno suites: 23 of 23 pass.
- A plain rerun of the language server suite: 643 passing, 0 failing, 7 pending.
- `pixi run diagnostics` on the finished branch: no errors or warnings. The formatting it applied
  and the regenerated MCP docs are the fixup.
- `pixi run test:all` on the finished branch: the Rust workspace, the six package suites, the 24
  Deno suites and the validator tests pass, and the browser suites pass, 126 vanilla and 109 svelte.
