# chore(release): bump every package to 0.6.0

- **Date:** 2026-10-21 12:47
- **Commit:** bdc8a445
- **Area:** Release version: the crates, the npm and JSR packages, the editor extensions, the
  website and the API data

## Problem

The branch's changes ship under 0.5.0, the version already released, and they break what 0.5.0
consumers rely on, so the release takes the next minor version.

## Fix

`mf bump --version 0.6.0` sets 0.6.0 in every crate, package manifest, extension and lockfile, and
in the version the generated API data records. The diff changes the version alone.

## Verified

`pixi run build:cli` and `cargo check --workspace --locked` finished with no warning against the
updated lockfiles.
