# fix(core): read a type as an array, a generic or an object only as a whole

- **Date:** 2026-10-18 13:24
- **Commit:** 31ad6f48
- **Area:** `macroforge_ts` built-in derives

## Problem

A field typed by a function returning an array, `(value: true) => string[]`, was cloned as
`[...value.field]`, compared and hashed as an array, and `ReadonlyArray<(value: X) => string[]>` as
an array of arrays, none of which type-checks. `Partial<User> | Array<(value: User) => Date>` was
refused as a `Partial` of a type written in place. A union whose first member is an object written
in place, `{ "key with space": undefined } | ReadonlyArray<string>`, defaulted to `({})`, without
the key it requires. Default gave a function inside a tuple or an object a call of its return type's
default, `DateDefaultValue()`.

## Cause

The readers of an array took a `[]` at the end of the text as the type's own, where a function's or
a conditional's last part ends in it. `parse_generic_type` took the text between the first `<` and
the last `>`. The default of a type checked for an object written in place, by its first letter,
before it split a union. `default_refusal` had no arm for a function.

## Introduced

`d60fa9da` (2025-12-14, "Add detailed documentation comments to all public types and functions")
documented `parse_generic_type`, whose first and last angle it has read since; `1cc2f3c4`
(2026-10-08, "feat(core)!: release 0.5.0 with Rust-shaped derives and shared foreign handlers")
added `array_element_type`; `5b6d9d6f` (2026-10-12, "fix(core): default a Required, a Pick and an
object type written in place by their fields") checked for an object before a union.

## Fix

A `[]` after a function's or conditional's last part is that part's own
(`scan::ends_in_its_last_part`), a generic's `<` has to close at the end of its text
(`scan::angle_unwrapped`), a union is defaulted before an object is read, and a function a default
would have to hold is refused by name.

## Verified

Ran `cargo test -p macroforge_ts_syn --lib` (195 passed);
`cargo test -p macroforge_ts --features test-macros --lib` (776 passed), whose tests pin
`array_element_type` over function, conditional and grouped types, `parse_generic_type` over a union
of generics, a qualified name and a `>` in a string, a union of an object defaulting to the object,
and Default refusing a union defaulting to a function by naming it;
`pixi run test:conformance:update` (10 passed), with the regenerated snapshots reviewed by the lines
that changed, in which two edge cases no longer look up a tuple by name; and the `edge-scanned`,
`exact-types` and `strict-lib` testground suites, whose `ScannedPicks` clones and compares an array
of functions and defaults its union to the object. Found by type-checking a corpus of 150 generated
field types.
