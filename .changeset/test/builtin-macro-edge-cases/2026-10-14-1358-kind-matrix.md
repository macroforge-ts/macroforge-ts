# test(testground): derive each built-in on the declaration kinds no edge case covered

- **Date:** 2026-10-14 13:58
- **Commit:** 4540e28d
- **Area:** testground

## Problem

No edge case derived Default on an enum, the orderings and Hash on an object alias, or the value
traits on an intersection alias, so a break in any of them would have passed every suite.

## Fix

A `kind-matrix` edge case derives each of them, and its suite runs the generated functions: the
enum's default is the member marked `@default` rather than its first, an object alias compares and
orders field by field, and an intersection alias clones, compares, orders and hashes over the fields
of both members.

## Verified

Ran `pixi run test:testground` (48 Deno suites, 13 validator files of 638 steps and 236 browser
tests in Chromium, all passed), in which the edge case expands and its three tests pass, and the
exact-types and strict-lib suites type-check it.
